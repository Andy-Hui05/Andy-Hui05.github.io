For this assignment I used the Bigfoot Field Researchers Organization (BFRO) reports dataset, where each row is one reported sighting or encounter.

## Chart 1: Bigfoot Reports over the Years

<vegachart schema-url="{{ site.baseurl }}/assets/json/bigfoot_plot1.json" style="width: 100%"></vegachart>

This plot shows the number of reported Bigfoot sightings submitted every year, these sightings are split into multiple classifications (A, B, C). I used a stacked area chart so I can see both the total as well as the individual parts of the reports. When creating this graph, the specific parameters was Year(which is time, thus I used T) and amount(fundamentally quantitative, thus I used Q). In addition to the X and Y, I used the nominal coloring since I was only concened that the different categories are distinguishable. Finally for the tooltip I defined the three important parameters that make up the graph.
## Chart 2: Location of Bigfoot Sightings

<vegachart schema-url="{{ site.baseurl }}/assets/json/bigfoot_plot2.json" style="width: 100%"></vegachart>

This plot is meant to show where and when each bigfoot sighting happens, thus I created two charts to help visualize both where and when these sighting occured. The first one is a map of the U.S where each dot is its own datapoint and records where and when each sightings happen. Alongside the state and county the map includes the longitude and latitude so that anyone can check where exactly the sightings occured rather than a vague location. In addition to the map there is a bar graph that counts the number of data points corresponding to the season. This is because it can be difficult to count or conceptualize the number of sightings over the years.
## Interactivity

Plot 2 uses a selection for its interactivity, clicking one of the season bar lowers the opacity of all the other season for botht he bar and map. This helps more easily show where the datapoints corresponding to the season are, this was an issue due to the sheer number of data points that overlap making it difficult to distinguish.
